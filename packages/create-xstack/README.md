# create-xstack

This is an alias package for [`xstack`](https://www.npmjs.com/package/xstack).

## Usage

```bash
npx create-xstack@latest
```

or

```bash
bun create xstack
```

For full documentation, please visit [xstack.dev](https://xstack.dev/).

## About

`create-xstack` is the package-manager entry point for `bun create xstack`, `pnpm create xstack`, and `npm create xstack`. It delegates to the `xstack` CLI.

All functionality is provided by the main [`xstack`](https://www.npmjs.com/package/xstack) package.
