## Philosophy

- Roll your own stack: pick only what you need, nothing extra.
- Composable product templates: select business modules and providers without hand-assembling their integrations.
- Latest dependencies: always current and stable by default.
- Free and open source: forever.

## Get Started

### Prerequisites

- **Node.js LTS** - [Download from nodejs.org](https://nodejs.org/)
- **Git** (optional) - [Download from git-scm.com](https://git-scm.com/) - if you want to initialize a git repository
- **Bun** (optional) - [Download from bun.com](https://bun.com/) - if you want to use Bun as your package manager

### CLI (prompts)

```npm
npm create xstack@latest
```

Follow the interactive prompts to choose your infrastructure, feature modules, providers, languages, and addons.

Skip prompts and use the default stack:

```npm
npm create xstack@latest --yes
```

### Template Builder (UI)

Visit [/new](/new) to start from **Shell**, **Starter**, or **Global SaaS**. Shell includes Next.js, Drizzle, SQLite and internationalization; Starter adds authentication; Global SaaS adds authentication, email, admin, payments and credits.

Choose modules first, then configure OAuth, email/payment providers, locales, signup credits, infrastructure and deployment. Automatically required modules and compatibility errors come from the generator catalog. The Preview tab renders the generated file tree; Save/Load and Share preserve provider and module settings. The UI does not collect credentials, randomize the stack, or expose the CLI's validation bypass.

Shell is a Builder preset, not a `--preset shell` CLI value. Use `--yes` for the default CLI shell or `--features none` with explicit infrastructure flags. The CLI still supports its separate `--template` technology presets.

Open the hosted builder with:

```npm
npm create xstack@latest builder
```

### AI agent (plugin)

Let your AI assistant build the stack for you. Install the xstack plugin, then describe what you want in plain English — it plans a valid stack and scaffolds it for you.

```bash
# Claude Code
/plugin marketplace add ziyu/xstack
/plugin install xstack@xstack
```

Then ask: _"create a fullstack app with Next, Hono, Postgres and Better Auth"_. Also works in Codex, opencode, and any MCP-capable agent — see [Use it inside your AI agent](/docs/cli/agent-workflows#use-it-inside-your-ai-agent).

## Common Setups

### Default Product Shell

```bash
xstack my-webapp --yes
```

The default shell uses Next.js full-stack, SQLite, Drizzle, Turborepo, and no optional feature modules or separate API layer.

### SaaS Product Template

```bash
xstack my-saas --preset saas-global \
  --providers auth:none email:smtp payment:polar \
  --module-options i18n.locales=zh-CN credits.signupBonus=50
```

`auth:none` disables OAuth while retaining email/password authentication. SMTP and Polar credentials must be configured in the generated environment. Polar defaults to its sandbox; mock payments, if selected, are development-only.

### Convex + React + Clerk

```npm
npm create xstack@latest my-api \
  --frontend tanstack-router \
  --backend convex \
  --features auth \
  --module-options auth.engine=clerk
```

### Mobile App (Expo)

```npm
npm create xstack@latest my-native \
  --frontend native-uniwind \
  --backend hono \
  --database sqlite \
  --orm drizzle \
  --features auth
```

### Empty Monorepo

```npm
npm create xstack@latest my-workspace \
  --frontend none \
  --backend none
```

## Flags Cheat Sheet

See the full list in the [CLI Reference](/docs/cli). Key flags:

- `--frontend`: tanstack-router, react-router, tanstack-start, next, nuxt, svelte, solid, astro, native-bare, native-uniwind, native-unistyles, none
- `--backend`: hono, express, fastify, elysia, convex, self, none
- `--runtime`: bun, node, workers, none
- `--database`: sqlite, postgres, mysql, mongodb, none
- `--orm`: drizzle, prisma, mongoose, none
- `--api`: trpc, orpc, none
- `--features`: auth, email, sms, admin, payment, credits, none
- `--preset`: starter, saas-global
- `--addons`: turborepo, nx, vite-plus, pwa, tauri, electrobun, biome, lefthook, husky, starlight, fumadocs, ultracite, oxlint, mcp, opentui, wxt, skills, evlog, axiom, none
